This proejct aims to create a webview UI component for the Cosmic Desktop environment based on https://github.com/servo/servo, using https://github.com/pop-os/libcosmic (and iced, which libcosmic includes) as the UI toolkit. The webview UI component should use the servo embedding api https://servo.org/blog/2026/05/31/april-in-servo/#embedding-api.
A simple example libcosmic application should be built to demonstrate the basic functionality of the webview component.
